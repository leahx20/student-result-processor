# Student Result Processor

## Description

This project is a simple Student Result Processor developed using
Python and Object-Oriented Programming (OOP).

The system accepts student details and three marks, calculates the
student's average mark, classifies the result, and displays a
formatted result report.

## Features

- Stores student information using objects
- Accepts three student marks
- Calculates average marks
- Classifies results as Distinction, Pass, or Fail
- Supports multiple students
- Uses Python classes and methods
- Uses a Python module for reusable functions

## Result Classification

| Average | Result |
|---|---|
| 70 - 100 | Distinction |
| 50 - 69 | Pass |
| 0 - 49 | Fail |
